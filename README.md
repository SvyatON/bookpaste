# BookPaste

Fabric mod for Minecraft `1.21.x` by `SvyatON`.

Paste large texts into writable books with automatic page splitting.

What it does:

- intercepts paste in the writable book screen
- splits large clipboard text across book pages automatically
- prefers paragraph, line, sentence, or word boundaries when cutting pages
- when the book becomes full, leaves only the unfinished tail in the clipboard and shows a notification

Usage:

1. Open a writable book.
2. Copy a large text.
3. Press `Ctrl+V`.

Compatibility:

- supported: Minecraft `1.21.x`
- a separate build is still recommended for other major version lines
